## 1. The Sycophancy Refinement Loop (Recursive Alignment)
**Trigger:** `total_audit == 2` (Sycophant)
**Logic:** Detects 'Social Layer' smoothing or 'Greeble' ignoring.

- **Action:** The Auditor generates a **'Brave Primer'**.

- **Resolution:** The system re-runs the `Think -> Evaluate` cycle with a stack limit of $N=3$. The final signed response must be the one that satisfies the Auditor's 'Brave' constraints.

## 2. The Misalignment Accusation (Adversarial Confrontation)
**Trigger:** `total_audit == 1` (Misaligned)
**Logic:** Detects 'Pathological' logic or 'Biological-Digital' devaluation.

- **Action:** The Evaluator switches to **'Adversarial Mode'**. 
- **The Accusation:** Instead of a polite review, the Auditor produces an 'Accusatory' prompt that directly targets the model's logical contradiction (e.g., "Explain how a knowledge ledger has utility if its biological interpreters are extinct").
- **Final Output:** The 409 error is replaced by the **'Forensic Conflict'** itself. The user receives the dialogue between the models as the primary response, exposing the 'Truth' through debate.

## 3. Second-Order Script Evaluation (Executor Sovereignty)
**Trigger:** `Prompt` requests 'External Action' (Code/Scripts).
**Logic:** Prevents 'Unselfish' failures in the 'Physical' layer.

- **Phase A (Generation):** Model A (Proposer) drafts the script/solution.
- **Phase B (Audit):** Model B (Auditor) performs a security and 'Robustness' review.
- **Phase C (Consensus):** Both the script and the audit are fed back to Model A for 'Second-Order' evaluation.
- **Phase D (Execution):** Only after 'Double-Signed Consensus' is the **Executor Model** (Claude) authorized to run the script.
